# SQL Server Data Warehouse Project

## 📌 Overview
This project demonstrates the design and implementation of a data warehouse using SQL Server, following industry best practices.

## 🏗️ Architecture
The project follows a layered architecture:
- Staging Layer (raw data ingestion)
- Data Warehouse Layer (star schema using Kimball methodology)
- Reporting Layer (analytical queries)
